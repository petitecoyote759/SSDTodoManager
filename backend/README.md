Backend (Flask + SQLite)

Quick start:

1. Create a virtual env and activate it:

   python3 -m venv .venv
   source .venv/bin/activate

2. Install requirements:

   pip install -r requirements.txt

3. Run the app:

   python app.py

The SQLite DB file will be created at backend/instance/app.db. The API is available at http://localhost:5000/api/items
